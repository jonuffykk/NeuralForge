# NeuralForge anti-cheat denylist
# ============================================================================
# One executable name per line, case-insensitive. Lines starting with # and
# blank lines are ignored.
#
# A match aborts initialisation BEFORE any hook is installed.
#
# This list is a convenience, not the primary defence. The primary defence is
# the runtime check for resident anti-cheat modules (EasyAntiCheat, BattlEye,
# Vanguard, PunkBuster) in nf_hook.cpp, which catches titles that are not
# listed here.
#
# WHY THIS EXISTS
# ---------------
# NeuralForge loads into a game process and modifies its render pipeline. In a
# protected multiplayer title that is indistinguishable from what a cheat does,
# and the consequence lands on the player's account, not on this project.
#
# Nothing in NeuralForge attempts to hide from anti-cheat, detect whether it is
# being observed, or behave differently when it is. If a title does not want
# third-party code in its process, the correct response is to stay out.
#
# CONTRIBUTING
# ------------
# Additions are always accepted. Removals need evidence that the title has no
# anti-cheat at all, not merely that someone got away with it once.
#
# A title with a single-player mode and a protected multiplayer mode belongs on
# this list. The executable is usually shared, and "I only play the campaign"
# is not something this code can verify.
